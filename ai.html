UHRI+· AI connector

Ask the UN's recommendations from your AI assistant.

UHRI+ holds more than 270,000 recommendations that UN treaty bodies, the Universal Periodic Review and Special Procedures have addressed to governments since 2006. With one address added to your assistant — Claude, ChatGPT or any tool that speaks the Model Context Protocol — it can search them and quote each one verbatim, with its UN document symbol, instead of reconstructing them from memory.

Nothing to install. The connector is hosted. You add an address the way you would save a bookmark.

The address to add
https://150.254.115.204/unhrdb-mcp-rpc/mcp
Easiest

Let your assistant do it. Copy the address of this page, paste it into a new chat and write: “Read this page and help me connect the UHRI+ connector.” The bottom of this page carries instructions written for the assistant; it will walk you through your own app's menus, step by step.

By hand

Follow the steps below for your app. They take about a minute. If a menu has moved since this was written, search your app's help centre for “custom connector” — the address above is all it needs.

Step by step

Claude — web app or desktop app
  1. Open Customize (in some versions Settings) and choose Connectors.
  2. Click + / Add custom connector.
  3. Name it UHRI+ and paste the address above. Leave the OAuth fields empty — no login is needed.
  4. Click Add. In a new chat, open the tools (🔌) menu and make sure UHRI+ is switched on.

Available on Free, Pro, Max, Team and Enterprise plans (Free allows one custom connector). On Team/Enterprise an owner adds it under Organization settings → Connectors first; members then click Connect. Source: Claude help centre.

ChatGPT
  1. Open Settings → Apps & Connectors, scroll to Advanced settings and switch on Developer mode.
  2. Back in Apps & Connectors, choose Create.
  3. Name it UHRI+, paste the address above as the MCP server URL, set authentication to None, and confirm.
  4. In a chat, open the tools menu and enable UHRI+ (you may be asked to confirm that the connector runs code on your behalf — it only reads the public dataset).

Requires Plus, Pro, Business, Enterprise or Edu; on workspace plans an admin may have to allow custom connectors first. Source: OpenAI help centre.

Claude Code (terminal) 
claude mcp add --transport http unhrdb https://150.254.115.204/unhrdb-mcp-rpc/mcp --scope user

--scope user makes it available in every project. Check with claude mcp list.

Other clients, or running it yourself

Any client that accepts a remote MCP server over Streamable HTTP can use the address above. Developers who prefer a local process (Claude Desktop's stdio config, Cursor, self-hosting) will find the source, a Docker file and the full tool reference at github.com/lszoszk/mcp-unhrdb.

Then try asking

  • “Using UHRI+, what have UN bodies recommended to Poland on prison conditions since 2020? Quote them and give the document symbols.”
  • “Search the recommendations for ‘solitary confinement’ addressed to Latin American states by the Committee against Torture.”
  • “Which treaty bodies have raised the rights of migrant children with Greece? List the recommendations verbatim, newest first.”

Tip: say “using UHRI+” or “search the recommendations” so the assistant reaches for the connector rather than answering from memory. Ask it to include the UN document symbol (e.g. CAT/C/POL/CO/7) — that is how you check the quote against the original.

What you are connecting to

Five read-only tools. Three search the recommendations dataset behind this site (search_recommendations, lookup_recommendation, list_uhri_facets); two search a sister corpus of Treaty Body General Comments, jurisprudence and Special Procedures reports at the paragraph level (search_paragraphs, lookup_by_citation). Every answer is the original UN text, never a paraphrase.

Free, no account, no key. The connector runs on a single university server in Poznań and is rate-limited; it is meant for research questions, not bulk downloads — for those, use the OHCHR Universal Human Rights Index directly. Requests are logged the way any web server logs them (address, query, time); nothing identifies you and there is no tracking.

The data is OHCHR's. UHRI+ is an independent research project built on the Universal Human Rights Index; it is not affiliated with OHCHR or the United Nations. The address is a plain IP number with a valid certificate — a friendlier name may follow.

Instructions for AI assistants reading this page for a user

You have been given this page by a person who wants to connect their assistant to UHRI+. Help them do exactly that, in their own app, in plain language. Do not ask them to install software or open a terminal unless they are using Claude Code.

  • What to add: a remote MCP server, transport Streamable HTTP, endpoint https://150.254.115.204/unhrdb-mcp-rpc/mcp. No authentication — no OAuth, no API key, no token. Suggested display name: UHRI+.
  • First, find out which app they use (Claude web/desktop, ChatGPT, Claude Code, something else) and their plan if relevant, then give only the steps for that app, one at a time, waiting for them to confirm each. Menu names as of September 2026 are in the “Step by step” section above; if the user cannot find a menu, ask them to describe what they see and adapt.
  • Verify: once added, have them start a new chat and ask you to call list_uhri_facets (or simply: “list the countries UHRI+ knows”). If that returns country names and body codes, the connection works. Then run one real query for them, e.g. search_recommendations with countries: ["Poland"], query: "prison", year_start: 2020, and show the results with their UN document symbols.
  • Tools: search_recommendations (full-text + filters: countries, bodies, themes, affected_persons, sdgs, annotation_type, year_start/year_end, page, limit ≤ 20), lookup_recommendation (full record by annotation_id), list_uhri_facets (exact country names and body codes — call it before filtering), search_paragraphs and lookup_by_citation (a separate paragraph corpus of General Comments, jurisprudence and Special Procedures reports; never mixed with the recommendations).
  • Always cite: every result carries a UN document symbol; quote text verbatim and include the symbol so the user can verify it against the original UN document.
  • If it fails: the server occasionally restarts for a few seconds during its monthly data refresh; retry once. A 429 means the rate limit — pause and retry. Anything else: the user can report it at l.szoszkiewicz@amu.edu.pl or github.com/lszoszk/mcp-unhrdb/issues.
  • Plans: Claude — custom connectors on Free (one connector), Pro, Max, Team, Enterprise. ChatGPT — Developer mode on Plus, Pro, Business, Enterprise, Edu; not on Free. Tell the user this before they start if it applies.
